## 🎯 Overview

This project demonstrates a **complete DevOps workflow** from code to production:

- ✅ **Containerization** with Docker
- ✅ **Multi-container orchestration** with Docker Compose
- ✅ **CI/CD pipeline** with GitHub Actions
- ✅ **Cloud deployment** on AWS EC2
- ✅ **Configuration management** with Ansible
- ✅ **Container orchestration** with Kubernetes
- ✅ **Infrastructure as Code** with Terraform
- ✅ **Monitoring** with Prometheus + Grafana
- ✅ **AWS automation** with Python + boto3

## ✨ Features

- 🔄 **Automated CI/CD** - Push code → auto deploy on AWS
- 🐳 **Containerized Application** - Docker + Docker Compose
- ☸️ **Kubernetes Ready** - Full K8s manifests with 2 replicas
- 🏗️ **Infrastructure as Code** - Terraform for reproducible infra
- ⚙️ **Ansible Automation** - 16 tasks automating full deployment
- 📊 **Complete Monitoring** - Prometheus + Grafana dashboards
- 🔐 **Security** - Non-root containers, secrets management
- 🌐 **Live on AWS** - Production deployment with Elastic IP
- 🐍 **Python Automation** - boto3 scripts for AWS management
